# **Ticket Classifier Project Guide**

## Model
- `The model is trained using SYNTHETIC DATA, so this model is good just for practicing purpose and not real world problames`
- `TFIDF is used to convert the text to computer landguage which is numerical. Then a pipeline is used alongside with Logistic Regression for the training and compiling of the model`

## Backend
- ` For the backend, I used FastAPI to build the backend and also the database. With the backend code, it might look strange to you if you are new in to fastapi, but my encouragement is that you should first of all go get a litle bit of fastapi basic before coming back to this project code, in that way you will not be totally lost since you will have a litle bit of idea. To run the fastapi file, you type **uvicorn main:app --reload** `

## Frontend
- `For the frontend, i used streamilt to build the frontend. And with the streamlit, you can build outstanding dashboard for you model in no time without any html and js knowledge. To run the streamlit file, you type **streamilt run streamlit.py**`

## Requirement
- ` The requirement file contain all the require libaries to run **main.py and streamlit.py**. To install the requirement, you type **pip install -r requirement.txt** `
